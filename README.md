# AdaptiveFiller

### Competition Management & Kumite Bracket Software

AdaptiveFiller is a Windows desktop application designed to assist with competition organization, participant management, and Kumite tournament bracket administration.

## Main Features

- **Competition Management:** Create, open, and save competition files in `.hya` format.
- **Participant Management:** Add, edit, remove, search, import, and export participant records.
- **Excel Integration:** Import and export participant lists using Excel files.
- **Category Management:** Organize competitions by age group, gender, weight category, and division.
- **Kumite Brackets:** Generate and manage tournament brackets.
- **Match Management:** Record winners and advance participants through tournament rounds.
- **PDF Export:** Export tournament brackets as PDF documents.
